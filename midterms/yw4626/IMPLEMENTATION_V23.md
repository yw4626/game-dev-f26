# v0.23 · 自动营火、连续出牌与牌堆动画

后续调整：所有新生成战斗统一每排5个敌人，保留原有波次深度以及整场生命、经验、攻击预算；已保存战斗不重新生成敌人。火焰魔杖 / 地狱火增加火球大小、拖尾、上窜火苗和像素余烬，属于视觉增强，不增加燃烧持续伤害或延长出牌等待。

节奏微调：按玩家反馈，将上述提速后的己方出牌、受击、死亡、补位和卡牌飞行时长增加20%。普通攻击现为288ms，受击162ms、死亡204ms、补位252ms；起手66ms、收招48ms。抽牌、弃牌、施法卡与回收飞行统一乘1.2，连续出牌队列和命中同步方式保持不变。

## 营火

当前经验成长模式（progressionVersion ≥ 7）进入营地立即调用休息：恢复最多18生命、不超过生命上限、不消耗金币，保持在地图中。当前火堆标记完成，满血经过也会完成此火堆；重访或读档不能重复恢复。若旧存档停在未确认的休息页面，继续游戏时自动完成休息。旧版升卡模式保留原有营地操作，用于历史规则回归。

回血复用治疗拾取光效、声音和生命浮字，不要求额外按键。

## 出牌手感

- 玩家攻击片段420→240ms，起手等待180→55ms，额外收招260→40ms；受击220→135ms、死亡240→170ms、补位340→210ms。长连击继续按全部实际命中事件压缩播放，经验飞行动画缩短至480ms。
- 正在播放己方出牌时，可以点击、拖放或按键预约下一张牌。待出卡面显示顺序，重复点击同一张不会重复入队；Esc 取消待执行队列，当前已经打出的牌继续结算。
- 每张牌轮到执行时再次检查它是否仍在手牌中、当前阶段和法力；不预扣法力。卡牌不可用时跳过并提示，升级、胜利、失败或离开战斗会清空未执行队列。
- 动画仍只播放已保存的结算结果；敌人行动、血量变化和后排补位继续遵守命中时序。

## 牌堆表现

- 左侧抽牌堆为像素牌背与叠层数量，右侧弃牌堆显示最近打出卡牌的图案与数量；点击仍可查看卡牌构成。
- 为保留既有连击回收规则，右侧数量与详情合并显示普通弃牌和当前连击暂存的普通牌；抽牌不足时引擎仍先回收普通弃牌、再回收连击牌。待销毁牌和持续角色牌不计入普通弃牌数量。
- 新抽到的牌从左侧飞出、翻面并落入其手牌位置。飞行中隐藏对应静态手牌，避免重复显示；抵达后更新牌堆数量。手牌重新布局时飞行目标跟随实际位置。
- 打出的牌先飞至施法位置，命中时继续飞往右侧弃牌堆。一次性牌在施法后缩小消散；持续角色卡飞入角色栏。结束回合时非保留手牌逐张收回右侧，回收牌堆时会从右向左飞回。
- 页面隐藏、切换画面与窗口尺寸变化清理飞行及隐藏状态；系统减少动态效果时直接显示最终状态。
