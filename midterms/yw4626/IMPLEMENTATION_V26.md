# v0.26 · 统一像素、落地视角与流畅度

本版按玩家最新反馈使用较低且统一的像素分辨率。保留暗色怪物造型，调整展示与渲染，不改动卡牌伤害、Boss 数值、掉落或存档进度。

## 画面

- 普通怪物、卡牌插画、角色和道具：32×32 基础图块；Boss：48×48。运行 PNG 采用最近邻缩放，不做平滑插值。更详细的原始生成图保留在 art-sources/unified-v26/。
- 新卡牌图集包含攻击、进化、技能、万能、法力、防御及四个角色的插画；同类升级牌可以共用对应物品图标。猫、宝箱、木箱、桶、火堆和拾取物来自补充图集。
- 场景画布 480×300，材质 64×64；五层继续使用不同材质和装饰。卡面色彩更沉稳，仍可按颜色区分类型。
- 战斗视角略向下，摄像机在可通行空间内后退一点，露出地面。怪物放大、抬高显示位置，前后排分别有脚底阴影；补位缩放以脚底为原点。
- 保留怪物名称、当前/最大生命、护甲、生命条及行动意图；仅去掉文字面板的底色、边框和阴影。文字本身有细描边以保证可读性。
- 移除出招文字条、Boss“后方”文字及后备角标。攻击特效、伤害数字、受击闪白、死亡与后排补位继续保留。

## 性能

怪物原本由许多 SVG rect 组成，现在每个精灵用一张内嵌 PNG，继续保留 sprite rows 供死亡粒子等特效读取。测试战斗的敌人区域总共约 110 个 DOM 元素。

战斗背景在楼层、视角、地图连接、门状态或画布尺寸变化时重绘。手牌/生命更新复用已有背景。测试中连续 30 次相同背景请求均命中缓存，没有重建地图或重绘背景。

探索时复用地图拓扑；如果暗门打开导致连接在原对象上发生变化，指纹会使缓存失效。移动仍使用当前位置计算摄像机坐标。没有通过跳过结算或改变动画时长来换取性能；上述测量是局部渲染指标，不是对所有设备帧率的承诺。

## 素材与验证

素材由内置 image_gen 生成。完整提示词：art-sources/unified-v26/PROMPT.txt 和 PROPS_PROMPT.txt。生成源图和运行 PNG 都已保存在工程中；运行时不访问图像服务。

349 项规则测试、43 项场景/交互/性能检查、74 项战斗动画回归全部通过，无浏览器脚本错误。结果分别见 evidence/tests-v26.txt、evidence/unified-v26/verification.json、evidence/combat-v17-ui/verification.json。窄屏背景只使用手牌上方的可见区域，验证了怪物文字不被卡牌遮挡。测试使用独立合成存档；截图的 999 生命、99 法力和 500 敌人生命仅用于验证。
