# v0.15：商人工坊、碰撞拾取与每层免费删牌

本轮落实用户指定的玩法与界面修改，不把这些自定义数值宣称为原版逆向结论。原有战斗、配方、职业与奖励结算继续沿用已实现规则。

## 商人

- 随机商品、递增刷新费用和一次性药剂继续保留。
- 扩槽工坊直接展开，按卡牌展示，不需要点击折叠项。显示已扩次数、现有槽位、价格和是否达到上限。
- 每次扩槽100金币，每种基础卡在本次探索最多扩两次。同名卡和该基础卡的进化版本共享扩槽记录；后续获得的同名卡也继承已购买槽位。
- 有宝石槽能力的卡，其容量上限调整为初始槽数加2。无宝石槽能力的角色卡保持不可扩槽。
- 已安装宝石不变，进化仍不占槽。旧存档已经购买的扩槽计入两次上限，不重复收费。
- 删除卡牌从商店移除。

## 地图交互

- 移动碰撞取代F键及探索中的交互按钮，支持WASD、方向键和屏幕移动按钮。
- 普通宝箱在进入该格时直接领取100金币，显示金币反馈并从场景中消失。每个宝箱只能领取一次；不治疗、不增加生命上限、不打开奖励选择页。
- 宝石箱继续提供宝石选择。取消后可以离开，再走入该格重新打开。
- 推车、木桶、箱子和石像先碰撞破坏，再碰撞拾取。其原有掉落规则保留。
- 商店走入即打开；离开后走出该格再走入可重访，库存和刷新次数不重置。
- 守关结束后，站在出口向前移动即可开始原有的三次自动挖掘，然后进入下一层。无需F键。

## 遗忘祭坛

- 每层在随机、可达且没有房间或其他物品的格子放置一个遗忘祭坛。随机位置由种子和楼层确定。
- 全层地图标注删牌位置，第一人称场景显示原创像素祭坛。
- 碰到祭坛后选择一张牌，免费删除；每层一次。角色卡不能删除，牌组至少保留角色卡和另一张牌。
- 暂时离开不会消耗机会；成功删除后祭坛失效。读档不会重新生成机会。

## 存档与实现

`worldRulesVersion=15`与`gemRulesVersion=15`区分本轮规则。页面加载旧档时进行迁移：补齐当前层祭坛、保留扩槽次数、转换尚未领取的普通宝箱页面。旧档已经领取的宝箱不再发奖，过去已增加的生命不会被回扣。

`dist/run.js`负责动作和经济结算；`dist/gems.js`提供本轮槽位容量；`dist/app.js`和`dist/world-v15.css`负责界面；`dist/dungeon-view.js`提供祭坛绘制。开发者侧栏可查看100金币扩槽、两次上限、已用次数、宝箱金币及本层祭坛状态。

保留旧版本的内部`interact()`接口供历史规则测试使用；当前游戏页面没有F键绑定或交互按钮。历史经济测试显式使用旧版本，不影响当前新局与迁移后的存档。
