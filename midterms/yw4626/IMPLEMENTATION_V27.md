# v0.27 · 战斗入场、待机、宅邸与怪物清晰度

本轮根据玩家反馈修复战斗切入卡顿与阵形飘动，加入轻微待机动作，放大花园宅邸，并恢复怪物的外形细节。规则、数值、存档结构不变。

## 战斗入场

旧入场 CSS 动画覆盖了阵形的 `translateY(-100%)`，结束时整个怪物组突然恢复定位。旧版实测跳位 350 CSS 像素，且切入时同步 PNG 编码和背景绘制带来一次 77ms 长任务。

现在把探索画布直接复制到临时画布，避免 `toDataURL()` 编码和再次解码；新战斗背景按约 5ms 工作预算分帧准备。怪物 PNG 提前解码，背景准备完成后再显示战斗 UI。过渡层只改变 transform 和 opacity，阵形本身只淡入，不改变定位。

视口变化或页面退出会取消过渡并清理覆盖层。减少动态效果模式直接切换画面。静态背景缓存和地图拓扑缓存继续有效。

## 怪物显示

- 普通怪物使用已有 64×64 原始运行 PNG，Boss 使用 96×96。30 个主题怪物与 10 个旧存档别名全部覆盖。打包脚本直接读取原文件字节，不进行缩小、锐化或重新采样。
- 战斗中的显示框和站位沿用 v26；更清楚的 PNG 放入相同逻辑框，因此不会因素材尺寸翻倍而把怪物放大两倍。
- 探索场景使用相同完整精灵的颜色网格，绘制循环仍按 480×300 画布像素工作。死亡粒子使用原有较小逻辑网格，避免增加粒子数量。
- 保留暗色统一调色板与最近邻缩放。卡牌、道具、墙地材质和背景画布不提高分辨率；每只怪物仍只有一个 SVG image，不恢复逐像素 DOM。
- 待机动作只作用于内部精灵，以脚底为轴做轻微呼吸、振翅或 Boss 的缓慢起伏。各怪物错开相位；冻结时暂停，受击、攻击、格挡、死亡、补位时关闭待机以防动画叠加。减少动态效果模式停止待机。

素材沿用 v25 已有生成资产，本轮没有重新生成图片。`scripts/package-creature-detail-v27.cjs` 可重建 `dist/creature-detail-v27.js`；源文件哈希及尺寸记录在 `evidence/entry-v27/creature-assets.json`。

## 宅邸

世界投影倍率从 2.8 提升到 5.4（约 1.93 倍）。建筑底部严格使用地面透视投影，靠近时限制高度并在顶部保留 4% 空间，不再向下移动建筑来容纳全貌。移除入口正前方的树篱、栅栏院落贴图，其他花园墙体仍正常遮挡。取消距离一格时突然绕过遮挡的规则。宅邸仍在守关前就存在；战斗中使用相同世界位置和战斗镜头，建筑底部位于后排怪物脚底之后。

## 验证

使用隔离浏览器存档检查真实地图移动触发战斗；不读取或覆盖玩家的本地进度。报告保存在 `evidence/entry-v27/verification.json`，包含帧间隔、阵形位移、原始 PNG 尺寸、待机脚底、受击暂停、减少动态效果和宅邸远近构图。旧版测量保留在同目录的 `baseline.json`。

53 项浏览器检查通过，新增花园 Boss 战后景位置检查。五组地图进入战斗场景均无阵形跳位、无长任务。宅邸远处与门前投影宽度分别约为视口 31% 和 54%；花园 Boss 战中建筑底部位于场景高度 35.5% 处，比最近的后排怪物脚底高约 89 CSS 像素。待机脚底与外部站位不变。

规则测试与受击、死亡、补位、敌人出手和生命同步的回归结果见 `VALIDATION.md`。这里的性能数据属于指定 Chrome 测试场景，不是对所有设备帧率的承诺。

## 后续：填满围栏缺口与世界空间夜空

按最新反馈，建筑与围栏缺口共用同一个投影范围，替代之前限制建筑高度、留出宽大缺口的布局。建筑保持原图宽高比，近距离允许屋顶自然超出画面；底部继续使用后景地面投影，不下移到怪物阵形。正对宅邸的验证场景中，建筑占场景宽度约 78%，底部在场景高度 32% 处。此规则替代前文的完整入镜和门前 54% 宽度。

`garden-sky.js` 缓存一张程序生成的像素全景，包含固定方位的满月、月面斑纹与分层乌云。渲染器以实际观察方向和仰角采样，转头时天空随世界方向移动；移动位置不会产生近景般的天空视差。月面可被乌云遮挡，树篱、建筑随后绘制以正确遮住天空。没有为天空增加持续的逐帧重绘或远程图片请求。

`scripts/verify-estate-sky.cjs` 使用独立存档验证建筑宽度、后景位置、满月可见、右转时月亮向左移动、云层变化以及整圈转向后画面完全复位。截图和结果位于 `evidence/estate-sky/`。

宅邸底部补入同深度的石砌基础、中央台阶及向草地疏散的碎石边缘，覆盖透明图块与地面的空隙，近景墙体和敌人仍可遮挡它。花园墙顶增加按世界坐标采样的枝叶冠层及暗色远景轮廓，替代整齐的天空切线；不使用屏幕固定渐变或模糊滤镜。349 项规则测试通过，夜空与宅邸浏览器检查通过，入场回归未发现新增跳位或长任务。
