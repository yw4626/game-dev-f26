# v0.25 · 统一暗色美术与固定场景

这是按玩家要求做的原型美术与场景调整，不是新逆向提取的原版规则。保留 v24 的五层主题、Boss 数值、FREE 新牌与已有攻击结算。

## 怪物与像素规格

五层的 25 种普通怪物和 5 种 Boss 全部换用同一组暗色哥特素材，取消之前的可爱老鼠、软泥和圆眼蝙蝠。普通怪物使用 64×64 图块，Boss 使用 96×96 图块，共用 32 色调色板。普通怪物统一像素倍率和脚底基线，Boss 保留更大的体型；后排只按距离缩小。旧存档中的基础怪物键也映射到新素材，不修改当前生命和战斗进度。

美术由内置 image_gen 生成，保留原始输出与[完整提示词](art-sources/gothic-v25/PROMPTS.txt)。运行素材见 dist/assets/gothic-v25/，预览见 evidence/gothic-v25-atlas.png；scripts/import-gothic-v25.py 可重建导入结果。它们不是 CC0 下载素材，也不是原游戏提取图像。原先的开源素材和许可保留归档；UI、道具和字体继续沿用现有资源。

## Boss 与宅邸

- Boss 战开始时，守关者已站在全部小怪后方，单独显示名字与“后方”标记；前排清空后通过原有补位动画走上前排。
- 等待中的 Boss 不执行前排意图，但仍属于存活敌人。已经支持后排目标的攻击可以按原有规则命中它，不再获得隐藏期间的额外免伤。
- 花园宅邸坐标由固定出口和入口方向决定，与玩家位置、击杀数无关；探索及战斗背景都包含它。远处按场景遮挡绘制，近处显示完整门面。
- 击败守卫只负责解锁大门并转向入口。未击败守卫时撞向守关位置进入战斗；胜利后向前进入图书馆，不挖洞。旧版 themeVersion=0 存档仍保留兼容行为。

## 场景与地图

花园加入暗天、枯叶、破损石路、铁栅栏和立柱；图书馆加入窗饰与肖像；地窖加入蛛网、木桶与湿地；监狱加入锁链、壁灯与排水纹理；吸血鬼藏身处加入彩窗和红色帷幕。装饰不占用互动格。

右下角地图显示高度由 140–220px 调整为 190–280px，整个操作区最大宽度由 650px 调整为 760px，地图占更宽的一列。地图逻辑尺寸和迷雾规则不变。

怪物样式允许 Web Animations 的 filter 生效，保留受击闪白和护甲闪光，不让静态像素样式覆盖动画。

## 验证

- 348 项规则测试通过，包含素材尺寸、宅邸固定位置、锁门战斗触发及后排 Boss 动画快照。
- 52 项浏览器检查全部通过，涵盖五层独立怪物、后排 Boss 可见、清场后走向前排、FREE 蓝框、锁门/开门、地图大小、移动端和真实闪白，无脚本错误；结果见 evidence/gothic-v25/verification.json。
- 74 项原有战斗动画回归通过，覆盖受击、死亡、后排补位、多种攻击特效和结算一致性；结果见 evidence/combat-v17-ui/verification.json。

浏览器检查使用隔离的合成存档；截图里的 999 生命或 99 法力是测试配置，不写入正常游戏或玩家存档。
